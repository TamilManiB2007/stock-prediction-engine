# 📈 Stock Market Prediction Engine

A powerful web application built with **Python** and **Streamlit** to visualize stock market data and predict future stock prices using Machine Learning.

## 🚀 Features

* **Real-time Data:** Fetches live stock data using Yahoo Finance (`yfinance`).
* **Interactive Charts:** Dynamic visualizations of Closing Price, Volume, and Moving Averages using Plotly/Matplotlib.
* **Prediction Models:** Uses Machine Learning algorithms (Linear Regression / LSTM) to forecast future stock prices.
* **User Friendly:** Simple and clean interface powered by Streamlit.
* **Date Filtering:** Analyze stocks over specific time periods (1 Year, 5 Years, etc.).

## 🛠️ Tech Stack

* **Frontend:** Streamlit
* **Language:** Python
* **Data Source:** yfinance
* **Data Manipulation:** Pandas, NumPy
* **Visualization:** Matplotlib, Plotly
* **Machine Learning:** Scikit-Learn / TensorFlow / Keras
